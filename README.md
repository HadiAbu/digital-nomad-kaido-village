[![Built with v0](https://img.shields.io/badge/Built%20with-v0.app-black?style=for-the-badge)](https://v0.app/chat/projects/tZIEWDLDMT3)

## Overview

A Next.js-powered platform designed to help digital nomads find their perfect stay in KaidoVillage, Thailand. The platform features modern design, seamless booking experience, and comprehensive information about accommodations and workspaces.

## ✨ Features

- **Modern UI/UX**: Responsive design with dark mode support
- **Property Listings**: Detailed property information with amenities
- **Booking System**: Streamlined booking process
- **Blog Section**: Updates and insights about digital nomad life
- **Newsletter**: Stay updated with latest offerings
- **Testimonials**: Real experiences from digital nomads
- **Contact Form**: Easy communication channel

## 🛠️ Tech Stack

- **Framework**: Next.js with TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn/ui
- **Deployment**: Vercel
- **Development**: Built with v0.app
